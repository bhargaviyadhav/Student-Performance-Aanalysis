# 📊 Student Performance Analysis

## 📝 Project Overview
This project analyzes student academic performance using Excel,
SQL, Python, Pandas, and Power BI.

## 🎯 Objectives
- 📈 Analyze student marks.
- 🧮 Calculate average marks.
- 🏆 Identify top-performing students.
- 📅 Analyze attendance.
- 🔍 Find missing values and duplicates.
- 📊 Create a Power BI dashboard.

## 🛠️ Tools Used
- 📗 Microsoft Excel
- 🗄️ SQL (SQLite)
- 🐍 Python
- 🐼 Pandas
- 📊 Power BI
- 💻 Google Colab
- 🌐 GitHub

## 📂 Dataset
The project uses a dataset of 100 students containing student details,
subject marks, and attendance.

## 🧹 Data Cleaning
Python and Pandas are used to check missing values, remove duplicates,
and prepare the data for analysis.

## 🔎 SQL Analysis
SQL is used to filter, sort, and summarize student records.

## 📈 Dashboard
Power BI is used to visualize student performance through charts
and key performance indicators.
