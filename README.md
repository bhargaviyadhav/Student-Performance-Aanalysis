# 📊 Student Performance Analysis

## 📝 Project Overview
This project analyzes student academic performance using Excel,
SQL, Python, Pandas, and Power BI.

## 🎯 Objectives
- To analyze student performance data.
- To find students with Maths marks above 70.
- To find Top 10 students by Total Marks.
- To count total students and unique student names.
- To find minimum English mark.
- To analyze student count by Gender.
- To create a simple Power BI dashboard.

## 🛠️ Tools Used
- 📗 Microsoft Excel
- 🗄️ SQL (SQLite)
- 🐍 Python
- 🐼 Pandas
- 📊 Power BI
- 💻 Google Colab
- 🌐 GitHub

## 📂 Dataset
The project uses a dataset of 100 students containing student details
- Student ID
- Student Name
- Gender
- Class
- Maths
- Science
- English
- Attendance
- Total Marks (Maths + Science + English)
- Average Mark

## 🔎 SQL Analysis
Queries included:
- Display only student names.
- Find students with Maths marks above 70.
- Count unique student names.
- Find the minimum English mark.
- Display all student records.
